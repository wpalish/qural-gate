# QuralGate

Оригинальный sandbox объявленного вызова по направлению reference10 Vapi. Admin задаёт контракт: оба описания RU/KK, модель read/write/blocked,1–20 входных и1–20 выходных плоских полей text/integer/boolean,обязательность/границы. Публикация фиксирует точную версию. Сотрудник вводит синтетические JSON-аргументы;сервер сохраняет точный текст,диагностику и снимок. Valid read_model разрешён автоматически;valid write_model ждёт другого администратора;blocked_model или плохие аргументы отклоняются. Другой admin один раз явно разрешает/отклоняет write_model с основанием. Только автор разрешённого запроса один раз вручную вводит соответствующий схеме результат. Это не выполнение инструмента,не Vapi integration,не реальный доступ/одобрение внешней операции.

FlatJSON без вложений/массивов,без coercion,дубликаты ключей/неизвестные поля/неверные типы отклоняются. Optional можно пропустить;null не значение типа. Текст непустой,maxLength;integer safe и в пределах;boolean только true/false. Preview не резервирует/не обязателен HTTP. Общая revision в одной BEGIN IMMEDIATE защищает формы и несвязанные правки;все действия имеют уникальный UUID requestKey,повтор отказывает. Время/автор/снимок/диагностика/решение серверные. Контракт/публикация в архиве закрывают новые запросы;прежний review/ack доступен по снимку. Нельзя скрыть pending/allowed запрос архивом. История и результаты неизменны,терминал не открывается. Нет полного промежуточного архива черновиков.

Общая область сотрудников,не tenant-изоляция. Admin контракт/публикация/независимый review/копии;staff запросы и собственный ack. JSON не подписан,проверка согласованности не подлинность;аккаунты/auth/audit не входят,restore пустой области. Никаких сетевых toolcalls,URLendpoint,секретов,реальных данных,LLM,голоса,звонков,сообщений,банка/договоров. Результат — ручной синтетический образец,не доказательство выполнения или правдивости.

Operate кабинет наследует TerimLine/SynaRoute: navy/paleblue/green,native labelled forms,видимый фокус,строгая иерархия запроса/диагностики/решения/результата. Точная цель задана поручением автономно продолжать все100,не нужна новая дизайн-пауза. Отличие от OrtaInbox:типизация аргументов и выхода/системный deny;отSynaRoute:один заявленный вызов/независимый review/ack;отTerimLine:нетцифр/таймера/телефонноймодели.
